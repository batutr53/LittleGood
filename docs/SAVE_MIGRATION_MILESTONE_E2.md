# E2B save compatibility

Authentic E1 fixture `tests/fixtures/planet-v085e1.json` was generated from commit914728f before regional source changes, through real1–21 progression and a second pending Iron Hills trading-post caravan. `tests/create_e1_fixture.gd` refuses to generate it from another commit. The original C/D fixtures remain unchanged. No real player's slot is used for fixtures or destructive QA.

Compatibility is opt-in: old E1 data loads without an automatic regional extension. Entering Iron Hills creates only the bounded version1 regional subrecord and new mountain run. Stock keys, kingdom version3, adventure version1, hero and equipment schema, military state and E1 trade schema remain. The old Wildwood run is parked intact, retaining killed enemies, unique boss reward history, chest/harvest/discovery state and remaining loot. Selection restores the canonical parked record rather than copying owners. New region fields and stored runs have explicit shape, kind and ownership validation.

Tests cover authentic C/D/E1 load-save-load, exact active expedition roundtrip, pending caravan identity and reservation preservation, history, finite node depletion, capacity failure/retry, repeated pickup/return/discovery rejection, old Wildwood restoration, malformed regional state, read-only behavior and repeated offline safety. Six legal seeded1–21 journeys extend into Iron Hills with real movement, fighting, gathering and home return. Quest21 is neither replayed nor rewarded by migration; no quest22 claim exists yet.

Regional materials use the existing stock/cargo rules. Mountain pickup additionally respects actual warehouse capacity before depletion; uncollected enemy loot remains in the persistent scene if it cannot fit. The finite mountain region cannot be refreshed using Wildwood's cleared-trail command. Home work and caravans deliberately freeze throughout an active adventure, even during absence. Returning deposits actual cargo once and restores home health/pause behavior.

Android QA uses a different application ID and private `beta-qa-world.json`. External process restart restores saved active mountains, depleted nodes, discovery and pending trade exactly, followed by a real native Home tap and saved banked resources. The player package's primary/backup/temp/settings bytes are checked separately. See measured test output in docs/benchmarks/phase085e2; no physical-phone test is inferred from emulator evidence.
