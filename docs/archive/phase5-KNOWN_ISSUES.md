# Known issues — LittleGod 0.5

- Android emulator performance varies severely. Earlier 0.4 samples were about 58 FPS; later 0.5 and preserved 0.4 runs both fell near 19–21 FPS. A zero-draw-call control also regressed. Post-restart samples and the final pass are retained in the performance report; sustained 60 FPS is not established on Android. Desktop reaches 60 FPS. See STATUS.md and PERFORMANCE_PHASE5.md for all measured conditions.
- No physical Android device was connected. Sustained hardware FPS, thermal/battery life, OEM safe areas/keyboards, physical two-finger gestures, accessibility and haptics remain unverified. Synthetic engine pinch events and ADB taps are not physical-device evidence.
- Engine/Forge resource and ObjectDB warnings remain on shutdown. Android can warn about cached shader reload and recompile. Startup/process spikes remain. Optional local diagnostics export fixed handled-error codes and unclean-session markers, not native crash stacks or a confirmed crash cause.
- The economy is generous and the research/content tree is modest. Four communities reach 320 total people in hour-long balance cases. Preferred habitats are species-based; behavior is a small deterministic simulation, not general AI. Real attachment, clarity and voluntary next-day/seven-day returns need human beta testing.
- Chronicle cards store illustrated state snapshots, not pictures of the historical moment. Permanent firsts and rare/community milestones are kept; older individual episodes rotate within 64 cards/128 IDs. Complete lifetime histories are not unbounded. A dead/missing companion displays a dash in the current relationship view; the recorded memory keeps its original names.
- Local session diagnostics retain only 200 recent events and 32 recent visit-day markers. They do not provide a global cohort denominator or permanent retention history. Optional export never uploads and contains relative UTC return days, not absolute dates or persistent identifiers.
- Native PNG saving was exercised on API 35. Native file dialogs require Android 10+; API 24–28 fallback storage access and OEM picker variants need further validation. There is no direct native social-share integration; users can share their exported PNG through their chosen app.
- The single current world and backup remain. New-world creation replaces the slot after its warning. Offline progression is compressed and capped at 480 ticks, while the report displays actual absence duration. Paused worlds stay paused.
- Sprite animation uses painted silhouettes with breathing, travel and poses. Dense canopies/groups can overlap. Silver creatures reuse the original atlas with an original shader rather than a new sprite sheet.
- Windows App Control blocked an earlier exported launcher. Use the official runtime through D:\LittleGod\Launch LittleGod.cmd. No bypass was attempted. Current Windows export exists but is not claimed as verified against App Control.
- Windows Computer Use could list the game but failed activation twice in this phase. Godot MCP supplied actual input, screenshots and runtime error inspection.
- No external human beta, iOS build, multiplayer service, external analytics, payments, store release or publication was performed.
