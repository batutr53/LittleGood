# Known issues — LittleGod 0.6

- Clean-host emulator performance reaches 58.05 FPS normal, 29.99 saver and 48.64 with 70 creatures. Sustained/max-population 60 FPS and physical-phone performance remain unverified. A matched same-APK control measured 19.68 FPS with two development editors open and 58.31 after closing them. Development-host load is a major measured factor; exact CPU/GPU/driver contention is not isolated. Earlier poor runs remain in PERFORMANCE_PHASE6.md. Generated build/documentation images now stay out of Godot's resource scan; duplicate UID warnings from those files are fixed.
- No physical phone is connected. Thermals, battery use, OEM safe areas/keyboards, real two-finger input, haptics and accessibility need hardware testing. ADB taps and synthetic engine pinch are explicitly separate evidence.
- Cold first-gift handler-to-post-draw samples varied; exact final and earlier values are in PERFORMANCE_PHASE6.md. These include engine/render queue work and exclude OS touch delivery/display scan-out; they are not physical touch-to-photon measurements. Startup and shader-cache variation remain. Shutdown ObjectDB/resource cleanup warnings persist from earlier milestones.
- This is a LOCAL social showcase, without accounts, online friends, remote reactions, real-time simulation or external analytics. Reactions stay on this device. A visit pauses both simulation timelines; imported creatures visually animate around recorded positions. Native PNG/JSON files can be manually shared, but direct Android share-sheet integration is absent.
- Native JSON Save/Open was exercised on the API 35 emulator, including successful file writing and validation/import. OEM pickers and API 24–28 storage fallback remain unverified. Visible public names are intentionally included: review names before sharing. The format rejects path/markup/control-bearing names; it is not a content moderation system.
- Local libraries contain eight replaceable snapshots, not an unbounded social feed. Public formats have strict limits and no images/scripts/resource references. Unsupported future versions are rejected rather than guessed. Save schema stays v1 with optional additions.
- Individual histories rotate within 64 memories/128 IDs, with important firsts retained. Favorites keep up to twelve small records; family links are lineage groups/recorded parent names, not a complete genealogy. Old saves gain recorded origins at migration time, not reconstructed biological birth data.
- Community culture uses the established models with existing props and tint differences. Landmarks, traditions, alliances and visible growth remain, while trade/rivalry/cooperation are simple bounded rules. Late progression and generous population/resource caps still need balance feedback.
- Wonders are conditional opportunities, not guaranteed daily events. Rare forest detail/habitat conditions can be unclear; real testers should judge whether clues are sufficient. There are no missed-day punishments, streaks, notification pressure or artificial waits.
- Diagnostics keep 200 recent events and 32 relative visit-day markers. First launch, actions, discoveries, sessions and fixed handled errors are local only. Unclean-session markers do not prove a crash; native crash stacks are not collected. Logs are not an all-time retention denominator and contain no invented human metrics.
- One current planet and recovery backup remain. New-world creation still warns before replacing the slot. Offline simulation is bounded to 480 ticks and reports actual absence. Imports never become the player's save.
- Use D:\LittleGod\Launch LittleGod.cmd through the official verified Godot runtime. The exported Windows executable is built but not claimed App-Control-verified; no security setting was changed or bypassed.
- No human beta, physical-device performance, iOS, paid service, store release or publishing was performed. Godot MCP supplied real rendered scene inspection. Windows Computer Use found the game but activation/capture failed twice with “foreground window did not report a process id.”
