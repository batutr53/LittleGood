# Save migration — Milestone C

The campaign version changes only on explicit Chapter III opt-in after ten claims. The shared save envelope/checksum, atomic write/recovery and original world schema remain. Campaign versions1 and2 retain their original playable caps5 and10 until the player opts into the next chapter. Version3 adds the private `adventure` object and zero leather/thornhide/herb/heart balances.

The authentic B fixture `tests/fixtures/planet-v085b.json` was generated by running the tagged B source (`age085-milestone-b`,6bb4100) through its legal campaign and queuing an unfinished Field Sickle. It was not created by relabeling current state. `devtools/create_v085b_fixture.py` records the reproducible extraction procedure. The earlier tagged A fixture and retained legacy saves also remain.

Verified transitions preserve2200 realm XP, the ten old claims and rewards, world cells, buildings, civilian/tool identities, exact industry state and pending queue. Repeated opt-in is rejected. New hero equipment references existing unique item IDs; civilian productivity tools remain valid and cannot become fake weapons. Old quests cannot be claimed again.

Active-run snapshots preserve position, hero health/XP/cooldowns, enemies and HP, attack state/timer/locked aim, pattern, RNG string, drops/taken bits, chest/plants, cargo and discoveries. Tests round-trip normal exploration, defeat, boss warning, completed boss and crafted/equipped artifact. A one-day offline load during an active run advances neither home ticks nor combat. Return safely restores the hero and transfers collected cargo once.

Negative tests reject dangling/wrong-slot item owners, duplicate actors, invalid boss patterns, malformed values and read-only mutations. Full-inventory pickup leaves its canonical drop untouched, and retry plus duplicate-callback checks preserve unique item count. The synthetic capacity copy is a boundary test; legal campaigns do not fabricate resources or completions.

Android upgrades snapshot the actual player's planet, backup, temporary slot and settings before installation, then compare exact bytes after startup/QA. Only `org.littlegod.livinguniverse.betaqa` is cleared. QA uses `beta-qa-world.json`, and performance uses private benchmark slots. Checksums/file-presence evidence are in `docs/benchmarks/phase085c/android-adventure.json`; real player save contents are not included in the report.
