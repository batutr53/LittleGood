# RPG source research

Source: https://wiki.korehberi.com/index.php/Kategori:Itemler

Research began 2026-10-25. Direct HTTP/API requests return 403; browser-readable source pages are used instead. Category enumeration and individually verified item statistics are tracked separately. Never treat category membership as a completed item-stat audit. Game names, artwork and balancing are original adaptations; reference images are not shipped as game artwork.

`item-catalogue.json` is the initial five-page root/category index (877 unique names versus the cached root's reported 876). `item-detail-audit.json` is the subsequent per-page extraction: all 877 URLs were successfully read after five retries; 492 yielded numeric table rows in the returned source windows. Remaining entries have no extracted numeric table and must not be treated as fully specified equipment. Returned source windows are not guaranteed to contain every upgrade variant; `individual_stats_complete` remains false. No missing values were invented.

The initial 28 original LittleGod equipment definitions are in `assets/rpg/equipment.json`, generated by `devtools/create_rpg_equipment.py`. These are a balanced starter subset, not a claim of 877 finished game items. Full family-by-family naming and numerical adaptation remains open.
