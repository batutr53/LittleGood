# Asset inventory and provenance

## Phase 3 additions

The phase-two atlas, fonts, audio, icons and shaders are retained. No raster asset was replaced and no generation service was called in this phase. New meadow flowers, lantern fireflies, friendship hearts, labels and discovery effects are original procedural runtime graphics in `world_view.gd`. Power/camera icons use the existing SVG textures in GUI texture controls. No new external asset license or paid service was introduced.

## Phase 2 additions

- `assets/phase2/world-atlas.png`: one 1024×1024 atlas, approximately 1.03 MB on disk. Twelve original imagegen sprites (six species and six environment/building props), the existing original tree, and original procedural camp/villager art. `atlas.json` and `devtools/phase2_assets.py` document frame layout and preparation.
- `assets/phase2/terrain.gdshader`, `water.gdshader`, `foliage.gdshader`: original runtime grain, glints and sway. The original atmosphere shader now adds warmer light.
- `assets/phase2/icons/*.svg`: eleven original consistent outline icons, generated by `devtools/phase2_icons.py`.
- `assets/phase2/nunito.ttf`, `lora.ttf`: downloaded from the official Google Fonts repository, SIL Open Font License; corresponding OFL texts are retained alongside the files.
- `assets/phase2/wind.wav`, `rain-loop.wav`: original precomputed local noise synthesis, three-second loops. Existing original gift/discovery/button WAV files are reused.
- `assets/phase2/splash-icon.png`: rasterized from the project's original SVG emblem, used for boot branding and Android launcher icon. `devtools/export_icon.gd` reproduces it through Godot.

The two generated input sheets remain at the Codex generated-images paths recorded in the phase-two asset script. Runtime/export uses the committed atlas and does not require those source sheets or any image API. No external paid image API, marketplace artwork or account was used.

## Phase-five additions

`assets/phase2/silver.gdshader` is original shader code recoloring the existing painted fox. Spring flow, community banners, companionship marks and the rainbow choir are procedural animated gameplay graphics. Chronicle illustrations reuse the original species/environment atlas; postcards capture the actual rendered world. No new raster generation service, stock pack or paid asset was used in phase five. Existing artwork, fonts and license files are retained.
