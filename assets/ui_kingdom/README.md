# LittleGod kingdom interface assets

Original SVG artwork created for this project: frame, button/hover/pressed/disabled nine-slice surfaces and human/stoneborn crests. Antique gold outlines, charcoal/olive interiors, burgundy selection, teal and crimson heraldry. No pixels were extracted from the reference screenshots.

Existing LittleGod lobby/character artwork is retained. Existing third-party LibreKO icons retain their provenance and license in assets/third_party/libreko; these are not claimed as new original drawings. Layout references supplied by the owner guide placement, not asset ownership. No paid asset pack was purchased or bundled.
